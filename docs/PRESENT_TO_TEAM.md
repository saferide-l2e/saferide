# SafeRide — 2-minute team talk

**Our Project board is already created** with 45 issues and the four columns Backlog, In Progress, In Review and Done. We have three team views. [Open board](https://github.com/orgs/saferide-l2e/projects/1/views/1).

> Hello, everyone! We have set up our GitHub home for SafeRide. We need to build and test a working bus-booking demo before **Friday, 16 October**.
>
> We have **three teams**. **Frontend** makes the pages people use. **Backend** makes buttons, bookings and rules really work. **Database** safely stores information. We all help test the app.
>
> There are **45 tasks** called GitHub Issues. **13** belong to Frontend, **14** to Backend, **8** to Database and **10** are shared. Each task tells you what to make, which part of the code to work on, how to test it, and what it means to finish.
>
> Start on [EVERYONE START HERE](https://github.com/saferide-l2e/saferide/blob/main/docs/TEAM_HUB.md), pick your team page and read one assigned task.
>
> Our task board has four steps: **Backlog → In Progress → In Review → Done**. In Review means another person checks your Pull Request. Done means code is in the project and tests passed.
>
> Please use AI to **learn and practise**, not only to copy code. Try to explain the part you built. Ask for help when stuck.
>
> We have **Tuesday, Wednesday and Thursday to build and practise**. On **Friday** we will show a demo. Every person should prepare to describe what they built, what they learned, and how they tested it. We want volunteers for the pitch and the live demo. Everyone is welcome to try.
>
> **Important:** Friday uses **fictional people and simulated ID approval**. We have not done real background checks.
