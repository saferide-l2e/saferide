# SafeRide — 2-minute group talk

Hi, everyone! We have a GitHub home for SafeRide. Our job is to build a working bus booking demo before Friday.

We have **three teams**. Frontend builds what people see. Backend makes the features work. Database stores and protects the information. We also help each other test the app.

We now have **45 GitHub tasks** called Issues. They are already named by team. **FE** means Frontend, **BE** means Backend, and **DB** means Database. The full steps are written inside each task, so no one has to guess what to build.

**Open this page now:** https://github.com/saferide-l2e/saferide/blob/main/docs/TEAM_HUB.md

Click your team. You will see your own task list. We will give each person one starting task, not the whole list. Please read it, ask questions, learn what you need, and try the work yourself.

We will use a **Project board** to see our progress. It has four steps: **Backlog → In Progress → In Review → Done.** A task goes to Done only after the code has been reviewed, added to the project, and tested.

**Tuesday:** Set up user accounts, data and page design. **Wednesday:** Get bus search and seat booking working. **Thursday:** Connect and test the whole ride, practise the demo, and fix bugs. **Friday:** Pitch SafeRide.

Everyone should be able to share what they built, what they learned, and what they tested. **Please think about volunteering to pitch the product!** We can practise together. You do not have to know everything to help.

**Reminder:** Real identity checks are not part of this Friday demo. We will use made-up sample profiles. Let's build carefully and learn together!
