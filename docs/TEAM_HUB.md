# SafeRide — Start here, everyone!

**Friday, 16 October 2026** is demo day. This page explains our work in simple words.

## What is SafeRide?
A passenger can search for a bus from **Jibowu to Mile 2**, check a driver's approved **demo** profile and book one seat. The seat is held for **10 minutes**. If the passenger does not check in, the seat can go to the next person on the waitlist. Both passengers and drivers are checked in our **fictional demo review**. We do **not** perform real background checks in this school prototype.

## A task moves in four steps
1. **Backlog**: No one has started yet.
2. **In Progress**: A teammate is building it.
3. **In Review**: A teammate has made a **Pull Request**, and someone else is checking the work.
4. **Done**: Code is merged, tests pass, and it works with the rest of SafeRide.

**Being assigned a task does not mean it is finished.** A pretty picture of a button also does not mean it works.

## A beginner's first day on GitHub
1. Sign in at https://github.com and accept the organization invite.
2. Open your team task list above.
3. Ask the lead: “Please assign me one task I can start.”
4. Open the task and read the steps. Look up words you do not know.
5. Comment on the task with your plan, even if it is only one sentence.
6. Open the repository on your computer, create a new branch, and make a small change.
7. Test it. Push your branch. Open a Pull Request and ask for feedback.
8. Learn from review comments. Fix mistakes. Celebrate the small steps.

**Word guide:** *Repository* = the project's shared code folder. *Issue* = a job to do. *Branch* = your own work area. *Pull Request/PR* = asking the group to check and add your work. *CI/tests* = checks that help catch mistakes. *Project board* = the task progress chart.
