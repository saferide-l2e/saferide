## What to do when you take a task
1. Ask the team lead to put your GitHub name on the issue.
2. Read the **whole issue**, including what must work and how to test it.
3. Put a short comment: “I am working on this. My first step is …”
4. Create a branch for that one issue. Ask for help if you do not know how.
5. Build a small piece, test it and open a Pull Request (PR).
6. Ask one teammate to check your PR. Do not push your work straight to `main`.
7. After a reviewed PR is merged and tests pass, move the issue to Done on the project board.

**Important:** If you are new, ask to pair with someone. Learn one part, try it yourself, and show what you made. You do not have to solve every task alone.
